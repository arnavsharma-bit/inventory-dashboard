# inventory-dashboard

## Live URLs
- Frontend: https://inventory-dashboard-sand.vercel.app
- Backend: https://inventory-backend-ee7a.onrender.com

## How to Run Locally

**Backend:**
cd backend
npm install
npm run dev

**Frontend:**
cd frontend
npm install
npm start

## API Endpoints
- GET /inventory — get all items
- POST /inventory — add new item
- PUT /inventory/:id — update item
- DELETE /inventory/:id — delete item
